# Operational Hub

Interactive bilingual operations prototype for the Eastern companies. Eastern Medical Academy now lives inside the broader hub as one of its modules.

## Run locally

```bash
pnpm install
pnpm dev
```

The sign-in screen is a prototype. Use the prefilled credentials or select **Enter demo academy**.

## Included in this prototype

- English/Spanish interface
- Operational overview across six entities
- Global search with direct module navigation
- Interactive Operational AI assistant prototype
- Delivery roadmap with completed, in-progress, and planned integrations
- License tracking, renewal status, owners and alerts
- Staff/provider directory modeled from the shared EM-MSO Airtable
- Employee sign-in experience
- Eastern Medical Academy module
- Learning dashboard and course catalog
- Common training and specialization paths
- Interactive lesson and knowledge check
- Local training progress demonstration
- Printable internal certificate and downloadable JSON training record
- Team progress dashboard with CSV export

## Production notes

Authentication, persistent records, Airtable synchronization, notifications, LMS/HRIS integration, clinical content, HIPAA training, insurance compliance, procedure claims, and certification criteria require formal technical, legal, medical, and compliance review before production use. Prototype expiration dates and alert totals must be reconciled against the source records before operational use.
